# Аудит сайта

1. Краулинг (если свежего, за последние 7 дней, нет в `data/crawl/<домен>/`):
   `python -m seo crawl` (свой сайт) или `python -m seo crawl --domain <домен>`.
   ~5 с на страницу — для сайтов > 200 страниц запускай в фоне.
2. Аудит: `python -m seo audit --check-links 300` → `reports/audit-<домен>-<дата>.md` и `.csv`.
3. Если есть `YANDEX_OAUTH_TOKEN`: `python -m seo wm-diagnostics` — добавь в отчёт проблемы из Вебмастера
   (state `PRESENT`) и число страниц в поиске/исключённых.
4. Вручную проверь то, что скрипт не ловит:
   - `robots.txt` (`curl https://am-tech.ru/robots.txt`): нет ли запрета нужного, есть ли `Clean-param` для
     utm/yclid/фильтров, указан ли sitemap;
   - выборочно 3–5 ключевых страниц через `python -m seo page URL`: H1 содержит ли тип товара, а не только модель;
     есть ли коммерческие блоки (цена/КП, характеристики, документы, лизинг, доставка, гарантия);
   - дубли (одинаковые товары под разными URL), пустые/тонкие категории, страницы-сироты.
5. Сравни с прошлым аудитом в `reports/` — что исправлено, что появилось.

## Отчёт пользователю

Коротко, по-русски, таблица приоритетов:

| Приоритет | Проблема | Страниц | Пример URL | Что сделать (было → стало) |
|---|---|---|---|---|

Приоритет: **P1** — мешает индексации/ранжированию массово (noindex, 4xx/5xx, дубли title, нет H1 у категорий),
**P2** — снижает релевантность (слабые title/H1, мало текста на категориях, нет Product-разметки),
**P3** — гигиена (alt, длина description). Для каждой задачи — конкретные URL из CSV.

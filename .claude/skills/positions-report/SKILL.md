# Отчёт по позициям

## Данные
1. `python -m seo wm-queries --days 28` → `data/positions/webmaster_<дата>.csv` (реальные показы, клики,
   средняя позиция по всем запросам, где сайт показывался; сравнение с прошлым снимком — колонка `delta`).
2. `python -m seo serp` по `data/semantic_core/core.csv` → `data/positions/serp_<дата>.csv`
   (точная позиция в Москве, наша и конкурентов, «ранжируется не целевая страница»).
3. `python -m seo metrika pages --days 28` → органический трафик и цели по страницам входа.
Нет доступа к чему-то — сделай отчёт по тому, что есть, и явно напиши, чего нет.

## Анализ
- Распределение по зонам ТОП-3 / ТОП-10 / ТОП-20 / ТОП-30 / 30+ и изменение к прошлому снимку.
- **Быстрые победы**: запросы с позицией 4–10 (→ ТОП-3) и 11–30 (→ ТОП-10), отсортированные по показам.
  Для каждого — целевая страница и конкретное действие (см. таблицу стратегий в CLAUDE.md).
- **Просадки**: `delta` ≤ −3 — найди страницу, проверь изменения (статус, title, контент), выдачу (кто вырос).
- **Низкий CTR при хорошей позиции** (позиция ≤ 5, CTR заметно ниже соседей) — переписать title/description.
- **Нецелевые страницы**: запросы, где ранжируется не та страница, — перелинковка/усиление целевой.
- Страницы с трафиком, но без целей в Метрике — проблема конверсии, а не SEO; отметь отдельно.

## Отчёт пользователю
1. Сводка: распределение по зонам (сейчас / прошлый раз), клики и показы.
2. ТОП-10 быстрых побед: запрос, показы, позиция, страница, действие.
3. Просадки и причины.
4. Позиции против конкурентов по ключевым кластерам.
5. План на следующий период — 5–10 задач с приоритетом.
Сохрани отчёт в `reports/positions-<дата>.md`.

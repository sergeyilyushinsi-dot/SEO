# Семантика и новые направления

## 1. Расширение
- Seed-запросы — из `config/project.yaml → directions.*.seeds` (или от пользователя).
- `python -m seo wordstat "<seed>" --limit 300` для каждого seed (или `--file seeds.txt`) → `data/wordstat/`.
- Добавь запросы из Вебмастера (`python -m seo wm-queries`) — это то, по чему сайт уже показывается.
- Ассоциации Wordstat (`kind=association`) — главный источник **новых направлений**: смотри, какие смежные
  темы ищут те же люди (материалы, постобработка, услуги печати/сканирования, ПО, обучение, сравнение технологий).

## 2. Чистка
Убери: нецелевое (бытовые/детские 3D-принтеры, «скачать», «своими руками», игрушки, FDM-хобби), чужие бренды,
которых нет в ассортименте (оставь, если это запрос-сравнение «аналог X»), гео не по делу, мусор.
Спорное не удаляй — помечай `status=rejected` с причиной.

## 3. Точные частоты и выдача
- `python -m seo wordstat --file <очищенный.txt> --mode exact` → точная частота.
- Отсей запросы с точной частотой < 5 (кроме очень целевых B2B: модели, «купить SLM принтер» и т.п.).
- `python -m seo serp --file <очищенный.csv>` (колонка `keyword`) — ТОП-100 и наши позиции.
  Платно: при > 300 запросах предупреди пользователя.

## 4. Кластеризация и привязка
- `python -m seo cluster --freq <файл с exact_freq> --min-common 3` → `data/semantic_core/clusters_<дата>.csv`.
- Для каждого кластера: интент по ТОП-10 (коммерческий/информационный/смешанный), целевой URL на сайте
  (существующая страница из `data/crawl` или «новая»), текущая позиция, приоритет.
- Приоритет = спрос (сумма точных частот) × близость к ТОПу (11–30 — быстрый рост) × маржинальность направления.

## 5. Результат
- Обнови `data/semantic_core/core.csv` (не теряя старые строки, меняя `status`).
- Отчёт пользователю:
  - таблица кластеров: кластер, запросов, точный спрос, интент, URL, позиция, действие;
  - **новые направления** отдельно: тема, спрос, кто в ТОПе, какой тип страницы нужен, вопрос «есть ли у вас
    такой продукт/услуга?» — соответствие ассортименту подтверждает пользователь.

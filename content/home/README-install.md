# Главная am-tech.ru — установка (шаблон Elementor, редактируется без кода)

Слайдер с видео остаётся. Блоки ниже — шаблон Elementor из стандартных виджетов (`amtech-home-elementor.json`).

## Как попасть в редактор главной
Админка → «Страницы» → «Все страницы» → строка «Главная» → «Редактировать в Elementor».
(Или откройте сайт, будучи в админке, и в чёрной верхней панели нажмите «Редактировать в Elementor».)

## 1. Копия текущей главной (для отката)
В редакторе Elementor: стрелка ▲ рядом с кнопкой «Обновить» → «Сохранить как шаблон» → название
«Главная — до изменений» → «Сохранить».

## 2. Импорт нового шаблона
Админка → «Шаблоны» → «Сохранённые шаблоны» → кнопка «Импортировать шаблоны» вверху → выбрать файл
`amtech-home-elementor.json` → «Импортировать сейчас».

## 3. Вставка на главную
1. Открыть главную в Elementor. Оставить первый блок (слайдер), блоки ниже удалить
   (правый клик по блоку → «Удалить»).
2. Внизу страницы нажать серую иконку папки «Добавить шаблон» → «Мои шаблоны» →
   «Главная AM.TECH — блоки под слайдером» → «Вставить».
3. «Обновить». Autoptimize → «Удалить кэш».

## Как менять содержимое (без кода)
- **Текст и заголовки** — щёлкнуть по тексту на странице и печатать.
- **Фото модели** — щёлкнуть по фото → слева «Выбрать изображение».
- **Ссылка кнопки / заголовка / фото** — щёлкнуть по элементу → слева поле «Ссылка».
- **Новая модель** — правый клик по карточке → «Дублировать», затем поменять фото, название, текст, ссылку.
  Убрать модель — правый клик → «Удалить».
- **Логотип партнёра** — щёлкнуть по логотипу → заменить картинку и подпись; новый — «Дублировать».
- **Навигатор** (иконка слоёв внизу слева) показывает блоки по названиям: «SLM-принтеры AMT», «3D-сканеры»,
  «Интегратор», «Услуги», «Кейсы и партнёры», «Блог», «Заявка».

Не трогать: виджеты «HTML» с названиями «Стили главной (не удалять)», «Лента кейсов (обновляется сама)»,
«Лента статей (обновляется сама)», «Форма Bitrix24». Кейсы и статьи появляются в лентах сами — из последних
записей сайта.

## 4. Телефон без видео — `mobile-slider-no-video.html`
WPCode → «Добавить сниппет» → HTML → вставить текст файла → место «Сквозная шапка», «Везде» → включить.

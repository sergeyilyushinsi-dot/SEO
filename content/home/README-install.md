# Главная am-tech.ru — установка (вариант 2)

Слайдер с видео остаётся. Меняется всё, что ниже него, и поведение слайдера на телефоне.

## 1. Блоки под слайдером — `home-blocks.html`
1. «Страницы» → «Главная» → «Редактировать в Elementor».
2. Сохранить копию: правый клик по странице в навигаторе → «Сохранить как шаблон» (для отката).
3. Оставить первый контейнер со слайдером. Удалить контейнеры ниже: SLM / EBM / Керамика / MBJ / SLA /
   3D-сканеры / Геодезические / «Комплексные решения» / «Наши партнёры» / «Новости».
4. Под слайдером добавить виджет **HTML** и вставить весь текст `home-blocks.html`.
5. «Обновить». Autoptimize → «Удалить кэш».

В блоке есть форма заявки (Bitrix24, та же, что внизу других страниц) с `id="contact-block"` — кнопки слайдера
«Бесплатная демонстрация» и «Подробнее» теперь прокручивают к ней, а не уводят на /kontakty/.

## 2. Телефон без видео — `mobile-slider-no-video.html`
WPCode → «Добавить сниппет» → HTML → вставить текст файла → место **«Сквозная шапка»** (Site Wide Header),
«Везде» → включить → сохранить. Работает только на главной и при ширине экрана до 760 px: видео не
скачиваются (проверено: 0 запросов к .mp4 на телефоне, на компьютере видео как раньше), вместо них — фото
оборудования по теме слайда (AMT-32, KSCAN MAGIC, SLA-600, C-136) на тёмном фоне.

## 3. Заголовок H1 (в настройках слайдера)
Виджет слайдера → заголовок «Технологии аддитивного производства» → заменить на
«Промышленные 3D-принтеры по металлу и 3D-сканеры от российского производителя».

# Страницы статьи и кейса в дизайне блога

Файлы `single-news.php` и `single-cases.php` одинаковые. Шаблон сам понимает, что выводит: статью (`news`)
или кейс (`cases`). Собираются из `single.src.php`, стилей блога (`../case-template/blog-reference.css`)
и `single.css` командой `python3 build.py`.

Превью на реальных записях: `preview/`.

## Что сохранено из старых шаблонов

- **Шапка сайта:** `get_template_part('header-nav')`. Без обёртки `.color-white`, поэтому шапка обычная,
  как в блоге.
- **Хлебные крошки:** Yoast.
- **Автор:** аватар, имя и «Биографические сведения» из профиля пользователя.
- **Главное фото:** в шапке не выводится (только заголовок); миниатюра записи идёт в разметку Article. Если у записи есть ручная «Цитата» (excerpt), она выводится подзаголовком.
- **«Популярное»:** `random_news()`.
- **«Оборудование по теме»:** поле ACF `товары_в_этой_записи`. Если поле пустое — товары, на которые
  ссылается текст (`/product/…`). Если таких ссылок нет — первые 3 товара раздела каталога, на который
  ссылается текст (`/katalog/…`).
- **Форма связи:** Elementor-шаблон 3699 и стили формы Bitrix24 из старого `single-news.php`. Теперь форма
  выводится и у кейсов.

## Что новое

- **Светлая шапка страницы:** рубрика, H1, автор, дата, «Обновлено» (если запись правили позже, чем через
  неделю после публикации), время чтения.
- **У кейса — блок цифр.** Его собирает таблица «Коротко» в начале текста: заказчик, отрасль,
  оборудование и т. д. Сама таблица из текста при этом убирается.
- **Содержание по H2.** Справа — закреплённым блоком, на телефоне — раскрывающимся. Выводится, если в тексте
  от 3 заголовков H2. Заголовки получают якоря `id`.
- **«Материалы по теме» / «Похожие кейсы»:** 3 записи той же рубрики.
- **Разметка `NewsArticle` / `Article`** (JSON-LD) с автором, датами и картинкой. Yoast выводит только
  WebPage.
- **Статьи со своей вёрсткой** (свои колонки, содержание или `<style>` в тексте) выводятся в полную ширину,
  без нашего содержания. Правая колонка в этом случае уходит под текст.

## Установка (как для case.php)

1. «Внешний вид → Редактор тем» → `single-news.php` → скопировать старый код в файл на компьютер.
2. Вставить код нового `single-news.php` → «Обновить файл».
3. То же для `single-cases.php`.
4. Autoptimize → «Удалить кэш».
5. Проверить статью и кейс на компьютере и на телефоне.

Откат — вернуть старый код.

## Видеообзор — single-video_reviews.php

Собирается тем же `build.py` из `video.src.php` + `video.css`: общие функции и стили — как у статей.

- **Сохранено:** шапка сайта, крошки, автор, дата; плеер, описание и «Рекомендованные видео» —
  функция темы `display_video_post_page()` (её вывод только оформлен стилями); «Из блога» —
  `[random_blogs count="2"]`; «Оборудование по теме» (ACF, иначе по ссылкам в описании).
- **Убрано:** боковой список `[recommended_videos]` — он дублировал «Рекомендованные видео» под плеером.
- **Новое:** светлая шапка; «Вопрос инженеру»; форма связи (Elementor 3699), которой на видеостраницах
  не было; разметка `VideoObject` (contentUrl/embedUrl, миниатюра, дата). Выводится, только если у записи
  есть миниатюра.

Установка: «Редактор тем» → `single-video_reviews.php` → сохранить старый код → вставить новый →
«Обновить файл» → Autoptimize → «Удалить кэш».

# Новый шаблон страницы «Технологии» (/teknologii/) в дизайне блога

**Задача:** привести страницу https://am-tech.ru/teknologii/ (page ID 1731, шаблон `case.php`) к дизайну
страницы https://am-tech.ru/blog/ (шаблон `news.php`, блок `#amt-blog`).

Превью на реальных кейсах: `preview/desktop-1440.jpg`, `preview/mobile-390.jpg`.

## Что внутри

Один файл `case.php`, без зависимостей.

| Блок | Что выводит |
|---|---|
| Шапка | хлебные крошки Yoast (как в блоге), H1, вводный текст, кнопки, счётчик кейсов |
| Вкладки | «Все кейсы» и непустые термины `case_category`: сначала родитель, за ним дочерние (SLM / EBM / MBJ), плюс поиск по кейсам |
| «Новые кейсы» | 4 последних кейса: один крупный и три малых, как «Главное» в блоге |
| «Кейсы по направлениям» | корневые термины `case_category`: их описание и число кейсов с учётом дочерних |
| «Примеры работ» | сетка из 12 карточек и кнопка «Показать ещё» |
| Текст страницы | `the_content` страницы 1731, только если она не собрана в Elementor (иначе старая лента дублировала бы сетку) |
| CTA | тёмный блок с телефоном, почтой и ссылками на /kontakty/, /uslugi/, /katalog/ |

Карточки строятся на сервере через `WP_Query` (тип записей `cases`). Эндпоинт блога
`/wp-json/amt/v1/posts` кейсы не отдаёт (`found: 0`), поэтому шаблон в нём не нуждается.

Фильтр, поиск и «Показать ещё» запрашивают эту же страницу с `?amt_partial=1`, в ответ приходит только
HTML сетки с заголовком `X-Robots-Tag: noindex`. Новые функции и REST-маршруты в `functions.php` не нужны.

Без JS всё работает обычными ссылками: `?amt_term=<slug>`, `?amt_s=<запрос>`, `?amt_pg=N`. Canonical от
Yoast указывает на /teknologii/, поэтому дублей не будет.

Стили — копия стилей `#amt-blog` из блога. Правило full-bleed привязано к классу
`body.page-template-case` вместо `page-id-1733`.

## Установка

1. Сделать копию текущего `wp-content/themes/davlatos_theme/case.php`, например `case.php.bak`.
2. Загрузить новый `case.php` на его место. Имя файла то же, поэтому страница 1731 подхватит шаблон сама.
3. Очистить кеш (плагин кеширования / CDN), если он есть.
4. Проверить:
   - https://am-tech.ru/teknologii/ — вкладки, «Показать ещё» и поиск;
   - вид на телефоне;
   - `?amt_term=tehnologii-3d-skanirovaniya` — открывается отфильтрованная сетка.
5. Если что-то не так — вернуть `case.php.bak`.

Если шаблон `case.php` использует ещё какая-то страница, она тоже получит новый вид. По данным REST его
использует только 1731.

## Что меняется для SEO

- **H1:** «Технологии» → «Кейсы применения технологий 3D-печати и 3D-сканирования». Title и description
  Yoast не меняются.
- **Облако меток `case_tag`** из старой шапки убрано: половина меток пустые и дублируют категории. Архивы
  меток продолжают открываться.
- **Ссылки «Показать все»** на архивы `/case-category/…/` заменены вкладками. Архивы терминов остаются
  доступны, но выглядят по-старому — при желании их можно перевести на этот же шаблон отдельно.
- **Контент Elementor на странице 1731** (виджет `case_feed_widget`) больше не выводится. Удалять его не
  обязательно.

## Подписи вкладок

Короткие подписи вкладок задаются в функции `amt_cases_short_label()`. Для нового термина без подписи там
выводится его полное название.

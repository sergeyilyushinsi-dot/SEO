# Карточка товара в дизайне блога — woocommerce/single-product.php

Собирается `python3 build.py` из `product.src.php` + стили блога + `../single-template/single.css` + `product.css`.
Превью на реальных товарах (AMT-16, KSCAN MAGIC): `preview/`.

## Что сохранено
Шапка сайта, крошки Yoast, галерея Swiper (слайды теперь `large`, миниатюры `thumbnail` вместо `full`),
видимые атрибуты, краткое описание, кнопки «Запросить КП» и «Заказать звонок» с формами Bitrix24 по
категориям (та же разметка `data-modal` и модальных окон — их открывает `js/script.js` темы),
описание товара, «Преимущества» (`_custom_advantages`), видео («Файл видео»), документы («Документы
товара»), `[partners_display]`, видеоблок категории (`display_video_block`), `[recommended_news]`,
`footer-nav`, форма Elementor 3699.

## Что изменилось
- Всё на одной странице, вместо вкладок — липкое якорное меню (Описание · Преимущества ·
  Характеристики · Видео · Документы · Модели линейки · Заявка; пустые разделы не выводятся).
- Первый экран: 4 первых атрибута — блоком цифр; кнопки в стиле сайта (зелёной больше нет).
- Третья кнопка (раньше «Демонстрация» ничего не делала: скрипт темы обрабатывает только `request` и `call`):
  у SLM, EBM, MBJ — «Заказать печать» → калькулятор /uslugi/3d-pechat-metallom/#calc; у SLA — «Заказать печать» →
  /uslugi/sla-pechat/#calc; у сканеров и керамических принтеров — «Демонстрация» → форма заявки на странице.
- Характеристики — одна таблица; на телефоне строки «название / значение» друг под другом.
- Документ — карточкой со ссылкой «Открыть» (без встроенного просмотрщика PDF с cdnjs).
- «Модели линейки» — свои карточки той же категории (4 шт., картинки `medium`) вместо
  `[similar_products]`, где грузились картинки 2560 px.
- Видеоблок категории выводится, только если в нём есть видео (без «Видео не найдено»).
- Заголовки H1 в старых описаниях превращаются в H2; служебные заголовки «… — Описание» убраны.
- На телефоне старые описания со своей вёрсткой (сетки) перестраиваются в одну колонку скриптом —
  текст больше не уходит за край экрана.
- Стили компонентов нового стандарта описаний `amt-pd-*` (см. `reports/product-cards-2026-10-29.md`).

## Установка
«Редактор тем» → папка `woocommerce` → `single-product.php` → сохранить старый код →
вставить новый → «Обновить файл» → Autoptimize → «Удалить кэш» → проверить 2–3 карточки
(принтер, сканер, товар с документом, например C-136) и кнопки «Запросить КП» / «Заказать звонок».
